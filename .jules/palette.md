## 2025-03-05 - Floating Component Keyboard and Screen Reader Accessibility
**Learning:** Toggled or floating widget controls (like ChatWidgets) require careful accessibility considerations. In particular: (1) missing ARIA labels on icon-only control buttons makes them opaque to screen readers; (2) failing to shift keyboard focus automatically to the input field on toggle leaves users stuck in the background; and (3) shifting focus on initial render when hidden or using native key event overrides incorrectly ruins standard navigation flow.
**Action:** Use standard React refs and a first-render guard ref to smoothly focus the text input when opening the chat widget, return focus back to the toggle button when closed, replace deprecated onKeyPress with onKeyDown, and always provide descriptive aria-labels for all control buttons.
