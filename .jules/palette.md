## 2025-03-05 - Focus Management in Dynamic Chat Widgets
**Learning:** For interactive floating widgets like chat assistants, visual toggling without proper focus management degrades keyboard navigation and screen-reader accessibility. When the widget is opened, the focus should immediately shift to the primary input element. Crucially, when closed, the focus must be returned to the triggering toggle button so that keyboard users do not lose their focus position on the page. Utilizing a mount-guard ref (e.g., `isFirstRender`) is essential to prevent triggering focus callbacks during the initial component mount before any user interaction.
**Action:** Always implement explicit ref-based focus shifts for open/close states in toggleable components, and protect them using an `isFirstRender` ref guard to avoid initial mount side effects.
