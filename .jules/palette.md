# Palette's Journal - Critical UX/Accessibility Learnings

## 2025-05-14 - [Accessibility Enhancements for Chat and Navigation]
**Learning:** For interactive components like chat widgets, ARIA attributes (roles, expanded states, controls, and live regions) are essential for a complete screen reader experience. Focus management (e.g., auto-focusing the input on open) significantly improves the UX for all users by reducing friction.
**Action:** Always include focus management and proper ARIA relationships when implementing toggleable UI components.
