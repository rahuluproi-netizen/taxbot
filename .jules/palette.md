## 2025-02-18 - [Accessibility & Keyboard Navigation in Interactive Widgets]
**Learning:** Icon-only buttons (like floating chat triggers or navigation items using emojis/icons) completely lock out screen reader users and keyboard navigation tools if they lack descriptive `aria-label` or `title` attributes. Furthermore, utilizing deprecated events like `onKeyPress` instead of `onKeyDown` can fail to capture standard submit actions (like 'Enter' key submission) reliably across modern browser setups.
**Action:** Always complement icon-only actions with descriptive `aria-label` and `title` tags, wrap raw emoji icons in `role="img"` spans with their own text descriptions, use modern `onKeyDown` listeners, and declare proper HTML landmarks (like `<nav>` instead of `<div>`) for key page areas to offer fully-functional structural maps.
