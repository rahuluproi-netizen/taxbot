## 2025-03-09 - Accessible Chat Widget Focus & ARIA Management
**Learning:** Floating/toggleable chat widgets are highly prone to keyboard trapping or loss of focus when toggled. Using `aria-modal="false"` allows users to interact with background page contents while the chat is open, which is the desired behavior for persistent help widgets. Managing focus dynamically by focusing the text input on open and returning focus to the triggering element on close provides a seamless experience for keyboard and screen reader users.
**Action:** Use a `useRef(true)` guard (like `isFirstRender`) in `useEffect` hooks controlling focus shifts to prevent triggering focus transitions on initial mount. Always pair custom icon-only triggers with explicit `aria-label` and `aria-expanded` attributes.
